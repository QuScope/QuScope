API Reference
=============

``quscope.quantum_ctem`` is the main module and re-exports the full public
API (``from quscope.quantum_ctem import ...``, or the shortcuts re-exported
directly from ``quscope``). ``ctem`` and ``simulations`` provide the classical
reference implementations used to validate the quantum circuits.
